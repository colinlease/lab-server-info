# Lab Server information pages

Public homepage, privacy policy, and terms for the personal Lab Server monitoring
application. Static HTML with shared CSS, no JavaScript, and no build dependencies.

- Homepage: https://colinlease.github.io/lab-server-info/
- Privacy: https://colinlease.github.io/lab-server-info/privacy.html
- Terms: https://colinlease.github.io/lab-server-info/terms.html

GitHub Pages publishes the root of `main`. `.nojekyll` keeps the files unchanged.
This repository contains public information only, with no monitoring runtime,
status records, application credentials, or operational configuration.

Google/Cloudflare account setup and site ownership verification are performed
manually by the owner. A public information page does not itself establish Google
verification, enable email delivery, or activate monitoring.
