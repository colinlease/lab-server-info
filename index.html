Lab Server

Personal server monitoring, with useful alerts delivered by email.

Lab Server helps its owner keep track of server availability, running services and background jobs, backup health, and available system updates.

What it does

  • Checks for a missing server heartbeat from an independent monitoring service.
  • Reports operational failures and subsequent recoveries.
  • Provides a daily summary of outstanding issues and available updates.

Why it connects to Google

When enabled, Lab Server uses the Gmail API to send these notifications from its owner's authorized Gmail account to the owner's configured email address. It requests the gmail.send permission for that purpose.

This permission does not allow Lab Server to read the owner's inbox, browse existing messages, or access Google Drive files. Read the privacy policy for how authorization, notifications, and monitoring data are handled.

Personal use. Lab Server is operated for its owner's systems. This public site provides application information and policies; the monitoring application has no public account registration.
