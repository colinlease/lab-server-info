Privacy policy

Effective October 20, 2026

This policy explains how Lab Server Monitor, operated by Colin Lease, handles Google authorization, monitoring data, and information associated with this website.

Google access

Lab Server Monitor requests only the Gmail send permission (gmail.send) to send monitoring notifications from the authorized Gmail account to the configured recipient. It does not request access to read or search email, manage contacts, or access Google Drive. Backup status comes from server monitoring, not from reading backup contents through Google APIs.

Data collection and use

  • Authorization: OAuth credentials and tokens used to authenticate email delivery.
  • Notifications: sender and recipient addresses, message contents, submission identifiers, delivery status, and bounded error codes.
  • Monitoring: heartbeat times, service and job status, backup health, update counts, and incident history.

This data supports notification delivery, retry handling, duplicate prevention, and operational investigation. Reports exclude accounting records, backup contents, and raw application log messages.

Storage and disclosure

Cloudflare Worker secrets hold encrypted OAuth credentials; temporary access tokens remain in memory. Cloudflare D1 stores monitoring and delivery records, and the server retains a local report queue. Google processes message contents and addresses for Gmail delivery. GitHub hosts this public website. These providers may process data in other countries under their own terms and privacy policies.

Data is shared with these providers to operate Lab Server Monitor and may be disclosed when required by law. Google user data is not sold, used for advertising or profiling, or provided to AI models. Its use follows the Google API Services User Data Policy, including the Limited Use requirements.

Retention

  • Accepted local reports: normally removed after seven days.
  • Sent or cancelled cloud notifications: normally retained for 30 days.
  • Resolved incidents: eligible for removal after 90 days when no retained notifications remain.

Housekeeping runs while monitoring is enabled. Unprocessed events, unresolved incidents, and blocked or uncertain delivery records may be retained longer for investigation. The one-time setup-email receipt remains until explicitly removed to prevent repeat submissions.

Revocation and deletion

Google access can be revoked through Google Account connections. Revocation prevents further use of that authorization but does not delete stored records. To request deletion of application data or credentials, use the contact form on Colin Lease’s website.

Sent and received email remains subject to the relevant Gmail account’s deletion settings. Deleting application records does not delete Gmail messages or immediately erase provider backups.

Website and policy updates

This website has no forms, analytics scripts, advertising, or application tracking cookies. GitHub may collect request information to host and secure the site; see the GitHub Privacy Statement.

Policy revisions will show an updated effective date. Additional Google permissions or materially different data uses require updated disclosures and appropriate authorization. For privacy questions, use the contact form.
