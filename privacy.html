Privacy policy

Effective October 18, 2026

Lab Server is a personal monitoring application operated by Colin Lease for his own systems. This policy describes its use of Google services, its monitoring records, and this public information site.

Google access and its purpose

When authorized and enabled by its owner, Lab Server requests only https://www.googleapis.com/auth/gmail.send. It uses that permission to send server alerts, recovery notices, reminders, and daily summaries from the owner's authorized Gmail account to the owner's configured recipient address.

The application does not request permission to read existing email, search a mailbox, manage contacts, or access Google Drive. Information about backup health comes from operational monitoring on the server, rather than access to backup contents through Google's APIs.

Information processed

  • Authorization information: an OAuth client ID, client secret, refresh token, and short-lived access tokens needed to submit email.
  • Notification information: the configured sender and recipient, email subject and body, and Gmail submission identifiers returned after sending.
  • Monitoring information: service health summaries, heartbeat times, job and backup status, update counts, incident history, and delivery status or bounded error codes.

Monitoring reports are designed to summarize operational conditions. They do not include accounting records, backup file contents, or raw application log messages.

Storage and service providers

OAuth credentials are stored in encrypted Cloudflare Worker secrets. Temporary access tokens are used in memory. Monitoring records, queued notification contents, and delivery metadata are stored in Cloudflare D1. The server maintains its own local report queue.

Google processes message contents and addressing information to provide Gmail delivery. Cloudflare processes the monitoring and delivery data needed to operate the application. GitHub hosts these public information pages. These providers may process data in different countries under their applicable service terms and privacy policies.

Use and sharing

Information is used to authorize email delivery, notify the owner, manage retries, avoid duplicate notifications, and investigate operational or security problems. It is shared with the relevant service providers for those purposes and may be disclosed if required by law.

Google user data is not sold, used for advertising or profiling, or provided to AI models. Lab Server's handling of Google API data follows the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

When monitoring is enabled, accepted local reports are normally removed after seven days. Normal sent or cancelled cloud notification history is retained for 30 days. Resolved incidents without retained notifications can be removed after 90 days. Unprocessed events, unresolved incidents, and uncertain or blocked delivery records can be kept longer for investigation and reconciliation. Cloud housekeeping runs when monitoring is enabled.

Gmail's copies of sent or received messages remain subject to the relevant account's settings and deletion controls. Removing application records does not remove messages from Gmail or immediately erase provider backups.

The owner can revoke Google access through Google Account connections. Revocation stops future use of that authorization; existing application records must be deleted separately. Contact the operator to request deletion of stored application data or credentials.

This public website

These pages do not contain forms, analytics scripts, advertising, or application tracking cookies. GitHub may collect ordinary web request information, including IP addresses and browser details, to host and secure GitHub Pages. See the GitHub Privacy Statement.

Changes and contact

Changes to these practices will be reflected on this page with an updated effective date. Additional Google permissions or materially different uses require an updated disclosure and appropriate authorization.
